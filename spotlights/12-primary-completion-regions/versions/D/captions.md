# Spotlight 12-D · School completion, SDG regions compared, by sex: post captions

## LinkedIn

Primary completion: data for 57% of countries in Oceania (excl. Aus., NZ). Countries of each SDG region with any value; 60 of 156 have nothing after 2020.

Every child completing primary school by 2030 needs the rate in Sub-Saharan Africa to rise 5.4 points a year, against 0.9 points a year since 2000.

A statistician's note: "latest value" means each country's most recent estimate, so values sit in different years. A gap here is a gap in the data, not a judgement on any statistical office.

Which countries have found a way to measure primary completion more often, and what made it possible?

Method: countries and territories with any value in the database, by membership, each counted once; 2020 or earlier counts as not recent.

Data: UNESCO UIS, UN SDG Global Database (series SE_TOT_CPLR, extracted 1 Nov 2026), via the UN System Data Commons.
