A statistician's note: "latest value" means each country's most recent estimate, so values sit in different years and are not directly comparable. A gap here is a gap in the data, not a judgement on any statistical office.

Which countries have found a way to measure youth NEET rate more often, and what made it possible?

Method: each country's latest value in the database; 2020 or earlier counts as not recent; series SL_TLF_NEET, which the source labels the previous definition.
